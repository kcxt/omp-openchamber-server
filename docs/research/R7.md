# R7: stub fidelity

`test/contract/` runs the same scenarios against `test/stub-omp/omp` (default) and the real omp worktree build, both as `--mode rpc` children under the hermetic environment of PLAN §8 (`harness.ts`). `consumed.test.ts` asserts every frame field the sidecar reads, by type; the other files assert ordering and semantics. Result at the end of this round: 43 tests, identical pass on both binaries (see `docs/testing.md`).

## Differences found between the old stub and real omp (all fixed in the stub, each pinned by a contract test)

| # | Old stub | Real omp | Test |
|---|---|---|---|
| 1 | no `messageId` on message frames | every `message_*` frame has `messageId` (`msg-N`, per process) | consumed, stretch |
| 2 | `prompt` response `data:{}`; local commands answered with `prompt_result{agentInvoked:false}` for everything | response has no data; empty input / builtins answer `data:{agentInvoked:false}` with no `prompt_result` (extension commands still get `prompt_result{agentInvoked:false}`) | stretch |
| 3 | each queued prompt ran as its own `agent_start…agent_end` | steers/follow-ups are absorbed into the live run; queued prompts report together after the single `agent_end` | stretch |
| 4 | `steer` and `follow_up` did not exist; `streamingBehavior` ignored | steer at the next turn boundary, follow-up after the model is done; steer overtakes an earlier follow-up | stretch, entries |
| 5 | `abort` answered at once and never stranded a queue | `abort` answers after `agent_end`; with input queued the stretch strands (`sessionSettled:false`, no `session_settled`) | stretch |
| 6 | no `abort_and_restore_queue` / `abort_and_prompt` | both exist, see R1 | stretch |
| 7 | `get_available_models` returned a bare array | `{models:[…]}` (the sidecar accepts both) | consumed |
| 8 | `set_subagent_subscription` ignored; `get_subagents` always `[]`; no subagent frames | level validated and echoed; lifecycle/progress/event frames; async spawn keeps the stretch open | subagents |
| 9 | `get_entries{since:<unknown>}` returned everything | failure `code:"unknown_since"` | entries |
| 10 | `get_session_lease` reported the process's own unwritten session as held | held only after the first write | lease |
| 11 | transcript created at the first **user** message; `set_model` journaled only if a file existed; `set_thinking_level` not journaled | file created with the first **assistant** message (or by `new_session`/`fork`/`branch`/missing-path `switch_session`); `model_change{model,role:"default",resolvedModelIsFallback:false}` and `thinking_level_change{thinkingLevel,configured}` journaled in memory and written with the file | entries |
| 12 | `new_session` kept the session in memory | creates a header-only file and takes the lease | tree |
| 13 | `switch_session` to a missing path failed | opens an empty session that writes there | consumed |
| 14 | `compact` always succeeded with `{summary}` | refuses a small session (`"Nothing to compact (session too small)"` plus `manual_compaction_end{skipped}`), otherwise `{summary,shortSummary,firstKeptEntryId,tokensBefore,details}` with `manual_compaction_start/end` | entries |
| 15 | records without `id` dropped when loading | kept; leaf undefined, history empty | entries |
| 16 | `get_state.isSettled` ignored queue/async; `sessionFile` undefined before a write; no `queuedMessages` | `isSettled` = §3.1 predicate; `sessionFile` always a path; `queuedMessages{steering,followUp,liveSteered}` | consumed, stretch |
| 17 | no `/move` | builtin `/move <dir>` through `prompt` (R5) | tree |
| 18 | provider `stub` | any; `OMP_STUB_PROVIDER` selects it (default `stub`, `fake` in the contract harness) | harness |

## Fields the real omp lacks that the sidecar reads today

- `message.id` on user messages (`events.ts:938`, `ompMessageId`): absent in both the frame and the journal entry's `message`. The frame-level `messageId` exists; the journal entry id (`entries[].id`) is only learnable via `get_entries`. P1 adds the host id.
- (`agent_end.isTerminal` and `yielded` are both emitted by the current build; the old stub lacked `isTerminal`, now added.)

## Not covered by the contract (known gaps)

Goal continuation, auto-compaction, retries (`auto_retry_*`), `extension_ui_request` approval round trips, image prompts, `get_messages_page`, `cycle_*`, `bash` command execution, and the P1–P5 commands (their own patch tests). The stub models goals from source (`rpc-goal.ts`) only.
